Customizable Auto Rigger
June - July 2025

A work-in-progress set of customizable auto rigging programs, initially created for my Hammerhead Alien project as an auto rigger that could be adjusted to the character's unusual shape and rig it more efficiently. The arms created by the tool include built-in IK/FK switches, while the legs have variables for foot and toe roll. In the future, I look to complete the UI for my Spine rigger, combine the separate programs, and add improvements to ease of use.

Created for Autodesk Maya using Python, Visual Studio Code, and QT Designer
